# Cerase Skills (archived)

This repository is archived and no longer maintained. It held an early version of the `deck` skill.

Each Cerase skill now lives in its own repository, installed through the Cerase Marketplace. The deck skill is [`cerase-ai/deck-skill`](https://github.com/cerase-ai/deck-skill); the organisation's other public repositories are listed on [its profile](https://github.com/cerase-ai).
